VehicleBot: Multi-technique AI Chatbot

Python chatbot for cars, EVs, and automotive technology that combines rule-based conversation, similarity search, first-order logic reasoning, and CNN image classification in one program.

  • Task A, conversation: AIML patterns for greetings, EVs, hybrids, safety, and maintenance; TF-IDF + cosine similarity over a CSV Q&A base when no rule matches; domain spell-check and Wikipedia fallback.
  • Task B, logic: NLTK resolution prover over facts such as Electric(Tesla) and rules like all x. (Electric(x) -> Vehicle(x)). Users add knowledge with “I know that …” and query with “Check that …”.
  • Task C, vision: Keras CNN (car / motorcycle / truck) trained in a separate script, then loaded at chat time. An image command opens a file picker and returns a class with a SoftMax confidence score.
  • Logging: Every turn is timestamped to chat_log.txt.

Role: Sole author: AIML, knowledge bases, FOL inference, CNN training, and demo.
