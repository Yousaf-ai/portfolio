Autonomous Mobile Robot — ROS2

Group project applying cognitive computing to an autonomous mobile robot in simulation. The group was led by Akshay and Arjan; each teammate owned a distinct objective across 10 functionalities.

My contribution: I completed 3 of the 10 functionalities — object detection, goal position detection, and traffic rules — independently as my assigned objectives.

  • Object Detection: Basic detection and classification of objects (signals, poster-like landmarks) in simulation.
  • Goal Position Detection: Detection of goal markers using the object detection system in simulation.
  • Traffic Rules: Basic traffic sign recognition and navigation response in simulation.
